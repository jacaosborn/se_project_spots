### Intro

Project from Tripleten to make a webpage for a new photo sharing platform, Spots. The page shows user details and a number of images that can be liked by other users.

### Technologies and methodology

The project utilizes HTML and CSS to create a responsive site with 6 images on either 3, 2, or 1 column, adapting to screen sizes. It uses a media queries to adapt displays for smaller screens.
Additionally, Javascript is utilized to provide functionality to buttons and connect the app to a server via API.
